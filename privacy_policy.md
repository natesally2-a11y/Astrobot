# Политика конфиденциальности Stellarium AI

*Последнее обновление: июнь 2026*

## 1. Общие положения

Настоящая Политика конфиденциальности определяет порядок обработки персональных данных пользователей Telegram-бота Stellarium AI (далее — «Сервис»).

Сервис обрабатывает персональные данные в соответствии с:
- Федеральным законом №152-ФЗ «О персональных данных»
- Регламентом ЕС 2016/679 (GDPR)
- Правилами платформы Telegram

## 2. Какие данные мы собираем

### 2.1 Данные Telegram-аккаунта
- Telegram ID (идентификатор пользователя)
- Имя пользователя (first_name)
- Username (@username)
- Код языка

### 2.2 Данные рождения (при явном согласии)
- Дата рождения
- Время рождения
- Место рождения (город, координаты)
- Часовой пояс

### 2.3 Данные использования
- История астрологических чтений
- Вопросы, заданные ИИ-астрологу
- Данные подписки и платежей

## 3. Цели обработки данных

Мы обрабатываем ваши данные исключительно для:
- ✅ Расчёта натальной карты (астрологических вычислений)
- ✅ Создания персонализированных астрологических прогнозов
- ✅ Управления подпиской и обработки платежей
- ✅ Улучшения качества сервиса

## 4. Правовые основания обработки

- **Согласие** — обработка данных рождения производится только после явного согласия пользователя
- **Исполнение договора** — обработка данных, необходимых для оказания услуг подписки
- **Законный интерес** — обработка данных для улучшения сервиса

## 5. Передача данных третьим лицам

Мы **НЕ** продаём, не сдаём в аренду и не передаём ваши персональные данные третьим лицам, за исключением:
- **OpenAI API** — для генерации астрологических интерпретаций (передаются обезличенные астрологические данные, без привязки к личности)
- **Telegram** — в рамках работы платформы

## 6. Хранение данных

- Данные хранятся на защищённых серверах
- Срок хранения — до удаления аккаунта пользователем или прекращения работы сервиса
- Данные подписок хранятся в соответствии с требованиями финансового законодательства

## 7. Ваши права

### 7.1 Право на доступ
Команда `/my_data` — просмотр всех сохранённых данных

### 7.2 Право на переносимость данных
Команда `/export_data` — экспорт всех данных в формате JSON

### 7.3 Право на удаление (право быть забытым)
Команда `/delete_data` — полное и необратимое удаление всех данных

### 7.4 Право на отзыв согласия
Вы можете отозвать согласие на обработку данных в любой момент, удалив аккаунт

## 8. Безопасность

- Данные хранятся в зашифрованной базе данных
- Доступ к данным ограничен по принципу минимальных привилегий
- Регулярное обновление систем безопасности

## 9. Cookies и аналитика

Mini App не использует cookies для отслеживания. Аналитика не собирается.

## 10. Изменения политики

Мы можем обновлять данную политику. О существенных изменениях пользователи будут уведомлены через бота.

## 11. Контакты

По вопросам обработки персональных данных обращайтесь через бота @stellarium_ai_bot.
